# Awesome LMS

> Modern full-stack Learning Management System platform with course tracking and analytics

---

## 🚀 Overview

Full-featured Learning Management System enabling educators to publish interactive video courses, track student quizzes, and monitor learning outcomes.

---

## 🛠️ Tech Stack

`Next.js` • `React` • `TypeScript` • `Prisma` • `PostgreSQL` • `Tailwind CSS`

---

## ✨ Key Features

- **Chapter and video progression tracking with completion markers**
- **Student quiz assessments and automated grading**
- **Instructor analytics dashboard with revenue metrics**

---

## 📦 Getting Started

### Prerequisites

Ensure you have the appropriate runtime installed (Node.js 18+ or Python 3.10+ depending on project stack).

### Installation

```bash
# Clone the repository
git clone https://github.com/Nbail-Oc/awesome-lms.git

# Navigate into the project directory
cd awesome-lms
```

### Setup & Run

- If this is a **Node.js / Next.js** project:
  ```bash
  npm install  # or pnpm install / yarn
  npm run dev
  ```

- If this is a **Python / FastAPI** project:
  ```bash
  python -m venv venv
  source venv/bin/activate  # On Windows: .\venv\Scripts\activate
  pip install -r requirements.txt
  python main.py  # or uvicorn main:app --reload
  ```
